# The Hidden Chapter

A simple static book recommendation site, hosted on GitHub Pages.

## Before going live
- Replace the placeholder name "The Hidden Chapter" if you pick a different brand.
- Replace `YOURTAG-20` in `posts/*.html` with your Amazon Associates tracking ID (or swap each link for a SiteStripe link).
- Replace `you@example.com` in `about.html` with a real contact email.

## Publishing
Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
The site will be at https://4d1t-codezz.github.io/thehiddenchapter/.
